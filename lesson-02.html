بخش اول

تعریف فاصله

فاصله به اختلاف ارتفاع بین دو نت گفته می‌شود. این اختلاف می‌تواند بسیار اندک (مانند نیم‌پرده) یا بسیار زیاد (چندین اکتاو) باشد.

نکته بنیادین — فواصل صرفا «ریاضی» نیستند، بلکه احساس تولید می‌کنند. در واقع، کنترل احساس از طریق فواصل، همان چیزی است که به آن «موسیقی» می‌گوییم.

بخش دوم

انواع فواصل: ملودیک و هارمونیک

♪ فاصله ملودیک (Melodic)

فاصله‌ای که در آن دو نت به‌صورت جدا و پشت سر هم شنیده می‌شوند. این فاصله در ملودی‌ها استفاده می‌شود.

♫ فاصله هارمونیک (Harmonic)

فاصله‌ای که در آن دو نت همزمان شنیده می‌شوند. این فاصله در آکوردها و هارمونی استفاده می‌شود.

بخش سوم

دو ویژگی تعیین‌کننده: کمیت و کیفیت

الف) کمیت (Quantity)

فاصله بین خط‌ها و فضای خطوط حامل را می‌شماریم. مثلا اگر از خط اول به خط سوم برویم، فاصله عددی سه است.

نکته حیاتی: هنگام شمارش، نت مبدأ را یک در نظر بگیرید، نه صفر.
از C تا C = ۱ (یونیسون)
از C تا D = ۲ (دوم)
از C تا E = ۳ (سوم)

ب) کیفیت (Quality)

تعداد نیم‌پرده‌های بین دو نت، کیفیت فاصله را مشخص می‌کند.

کیفیت‌ها:
بزرگ (Major - M)
کوچک (Minor - m)
درست (Perfect - P)
افزوده (Augmented - A)
کاسته (Diminished - d)

بخش چهارم

روش گام‌به‌گام محاسبه فاصله

برای محاسبه دقیق هر فاصله، این دو مرحله را دنبال کنید:

مرحله اول (کمیت)

نت‌ها را بدون در نظر گرفتن علامت‌های Sharp و Flat بشمارید.

مثال: C تا E♭
از C تا E می‌شود ۳ (سوم)

مرحله دوم (کیفیت)

تعداد نیم‌پرده‌ها را محاسبه کنید و با جدول تطبیق دهید.

مثال: C تا E♭
سه نیم‌پرده است → سوم کوچک (m3)

بخش پنجم

جدول کامل فواصل پایه

فواصل از یونیسون تا اکتاو — با احساس و کاربرد
کمیت کیفیت نماد نیم‌پرده مثال از C احساس و حال کاربرد
1 درست P1 ۰ C → C سکون مطلق ایست‌های قطعه، لایه‌های ضخیم همون
2 کوچک m2 ۱ C → C♯/D♭ تنش شدید، ناآرام، مضطرب، تاریک موسیقی هارر، تریلر، ساسپنس، Black Metal
2 بزرگ M2 ۲ C → D حرکت طبیعی، ملایم، نه شاد نه غمگین ملودی‌های ساده، موسیقی احساسی
3 کوچک m3 ۳ C → D♯/E♭ غم، افسردگی، احساس عمیق انسانی گام مینور، سینمایی غمگین، Gothic
3 بزرگ M3 ۴ C → E شاد، روشن، مثبت، امید گام ماژور، پاپ، راک کلاسیک
4 درست P4 ۵ C → F قدرت، استحکام، حس «پاسخ» یا «انتظار» آکوردها، نه کاملا آرام و نه پرتنش
4/5 افزوده/کاسته A4/d5 ۶ C → F♯/G♭ شیطانی، ناپایدار، پرتنش ترایتون — فاصله شیطان
5 درست P5 ۷ C → G قدرت، استحکام، پایه آکوردها Power Chord، ستون موسیقی متال
6 کوچک m6 ۸ C → G♯/A♭ غم عمیق، جدایی، لحظات تراژیک فیلم عاشقانه غمگین، Dark Ambient
6 بزرگ M6 ۹ C → A لطیف، احساسی، امید در دل غم آهنگ‌های عاشقانه، حماسی روشن
7 کوچک m7 ۱۰ C → A♯/B♭ شور، احساس «بلوز»، قدرتمند Blues، Rock، Jazz
7 بزرگ M7 ۱۱ C → B تنش روشن، ناتمام، رویایی موسیقی فضایی، آکوردهای ماژور ۷
8 درست P8 ۱۲ C → C کمال، پایداری، تمام شدن پایان‌بندی قطعات، ملودی‌های حماسی

بخش ششم

مثال‌های تحلیلی در موسیقی معروف

مثال ۱: فاصله دوم کوچک (m2) — حس تنش و وحشت
Jaws Theme دوم کوچک
از John Williams

تحلیل: این دو نت با فاصله نیم‌پرده (E → F)، حس ترس و خطر قریب‌الوقوع را منتقل می‌کنند. یکی از معروف‌ترین کاربردهای فاصله m2 در تاریخ سینما.

مثال ۲: فاصله سوم بزرگ (M3) — حس شادی و روشنایی
Ode to Joy سوم بزرگ
از Beethoven

تحلیل: شروع ملودی با فاصله سوم بزرگ (E → G♯ در گام E ماژور). این فاصله پایه گام ماژور است و حس شادی و پیروزی را منتقل می‌کند.

مثال ۳: فاصله چهارم درست (P4) — حس قدرت و انتظار
Smoke on the Water چهارم درست
از Deep Purple

تحلیل: ریف اصلی با فاصله چهارم درست شروع می‌شود (A → D). این فاصله حس استحکام و قدرت را به ریف می‌دهد.

مثال ۴: فاصله ترایتون (A4/d5) — حس شیطانی و ناپایدار
Black Sabbath ترایتون
از Black Sabbath

تحلیل: ریف اصلی از فاصله ترایتون استفاده می‌کند (E → B♭). این فاصله در قرون وسطی «فاصله شیطان» نامیده می‌شد و پایه موسیقی متال است.

مثال ۵: فاصله پنجم درست (P5) — حس قدرت و پایه متال
Enter Sandman پنجم درست
از Metallica

تحلیل: ریف اصلی بر پایه فاصله پنجم درست (Power Chord) ساخته شده (E → B). فاصله پنجم درست ستون موسیقی متال و راک است.

مثال ۶: فاصله هفتم بزرگ (M7) — حس رویایی و ناتمام
Take On Me هفتم بزرگ
از A-ha

تحلیل: ملودی اصلی از فاصله هفتم بزرگ استفاده می‌کند. این فاصله حس «ناتمام بودن» و «رویاپردازی» را منتقل می‌کند و در موسیقی پاپ و فیلم مدرن بسیار استفاده می‌شود.

بخش هفتم

فواصل مرکب (Compound Intervals)

هر فاصله‌ای که بزرگ‌تر از اکتاو (بیش از ۸) باشد، فاصله مرکب نامیده می‌شود.

فاصله مرکب = فاصله ساده + 7

مثال‌ها: دوم بزرگ (M2) + اکتاو = نهم بزرگ (M9) · سوم کوچک (m3) + اکتاو = دهم کوچک (m10) · پنجم درست (P5) + اکتاو = دوازدهم درست (P12)

کاربرد در DAW — هنگام نوشتن آکوردهای گسترش‌یافته (Extended Chords) مانند آکوردهای ۹، ۱۱ و ۱۳، شما با فواصل مرکب سروکار دارید.

بخش هشتم

معکوس فواصل (Inversion of Intervals)

وقتی یک فاصله را معکوس می‌کنیم (نت پایین را یک اکتاو بالا می‌بریم، یا نت بالا را یک اکتاو پایین می‌آوریم)، فاصله جدیدی به دست می‌آید.

قوانین معکوس

درست ⇋ درست || بزرگ ⇋ کوچک || کوچک ⇋ بزرگ || افزوده ⇋ کاسته || کاسته ⇋ افزوده

فرمول عددی

نکته — ترایتون تنها فاصله‌ای است که معکوسش خودش است.

بخش نهم

فواصل افزوده و کاسته

الف) افزوده (Augmented - A)

فاصله‌ای که نیم‌پرده بیشتر از فاصله بزرگ یا درست باشد.

C تا F♯ = چهارم افزوده = ۶ نیم‌پرده
C تا G♯ = پنجم افزوده = ۸ نیم‌پرده

ب) کاسته (Diminished - d)

فاصله‌ای که نیم‌پرده کمتر از فاصله کوچک یا درست باشد.

C تا G♭ = پنجم کاسته = ۶ نیم‌پرده
C تا D♭♭ = دوم کاسته = ۰ نیم‌پرده

بخش دهم

نکات کلیدی

نکته اول: تفاوت مینور دوم و یونیسون افزوده

هر دو فاصله C تا C♯ و C تا D♭♭ از نظر تعداد نیم‌پرده یکسان هستند (۱ نیم‌پرده)، اما: C تا C♯ = دوم کوچک (m2) · C تا D♭♭ = دوم کاسته (d2). چرا؟ چون کمیت فاصله متفاوت است.

نکته دوم: ترایتون و معکوس آن

ترایتون تنها فاصله‌ای است که معکوسش خودش است: C تا F♯ = چهارم افزوده (A4) = ۶ نیم‌پرده · F♯ تا C = پنجم کاسته (d5) = ۶ نیم‌پرده. هر دو ترایتون هستند.

نکته سوم: فواصل در گیتار vs پیانو

در پیانو، فاصله C تا C♯ یک کلید فاصله است. در گیتار، همان فاصله یک فرت است. اما در DAW، هر دو MIDI Note Number یکسان دارند.

جمع‌بندی درس دوم

  • فاصله = اختلاف ارتفاع بین دو نت
  • دو نوع فاصله: ملودیک (پشت سر هم) و هارمونیک (همزمان)
  • کمیت = شمارش خطوط، کیفیت = تعداد نیم‌پرده‌ها
  • فواصل پایه: m2, M2, m3, M3, P4, A4/d5, P5, m6, M6, m7, M7, P8
  • معکوس فواصل: بزرگ ⇋ کوچک، درست ⇋ درست، افزوده ⇋ کاسته
  • فواصل مرکب = فواصل ساده + اکتاو
